# 🛒 Amazon Clone (Unique UI Version)

This project is a **modern Amazon-inspired clone** that replicates the layout of Amazon’s homepage while adding a **unique, modern UI**.  
It is designed as an educational exercise in **front-end web development**, showcasing responsive design, CSS animations, and creative UI enhancements.

---

## ✨ Features
- 🧭 **Glassmorphism Navigation Bar** with sticky header and search bar.
- 🎠 **Hero Section Carousel** with gradient overlays & floating category buttons.
- 📦 **Product Grid with Hover Effects** (zoom, quick view, ribbons).
- 🌙 **Dark Mode Toggle** for accessibility and modern look.
- 📱 **Responsive Layout** optimized for desktops, tablets, and mobiles.
- 📩 **Minimal Footer** with newsletter subscription & social icons.
